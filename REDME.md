# Word & Line Counter CLI

A small Node.js CLI that counts the lines, words, and characters in a text file.

## Requirements
- Node.js 18 or newer

## Usage
```bash
npm start sample.txt
```

## Example output
```text
File: sample.txt
Lines: 7
Words: 50
Characters: 294
```

If the file doesn't exist, the tool prints a friendly error message.
